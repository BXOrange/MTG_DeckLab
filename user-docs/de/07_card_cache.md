# 7. Karten-Cache

Der Tab **Karten-Cache** ist eine reine Übersichtsansicht — er zeigt
jede Karte, die die App jemals nachgeschlagen und zwischengespeichert
hat, als Raster von Kartenbild-Kacheln mit Details.

Hier gibt es nichts einzustellen: Karten werden automatisch zum Cache
hinzugefügt, sobald eine Deckliste sie erwähnt (im Tab "Deck
editieren" oder anderswo) — die Liste wächst also von selbst, während
du die App nutzt.

- Der Tab lädt seine Liste beim ersten Öffnen innerhalb einer Sitzung
  (nicht schon beim Start der App).
- **Aktualisieren** lädt die Liste neu — nützlich, wenn du gerade an
  anderer Stelle ein Deck mit neuen Karten importiert hast und diese
  auch hier sehen möchtest.

Zeigt der Tab "Noch keine Karten im Cache", importiere zunächst eine
Deckliste.
